# AcademiX Pro - User Manual

## 📖 Complete User Guide

### Getting Started

#### Step 1: Access the Platform
1. Open `index.html` in your web browser
2. Or run a local server: `python -m http.server 8000`
3. Navigate to `http://localhost:8000`

#### Step 2: Explore Dashboard
- View your learning statistics
- See AI-recommended resources
- Check your progress across subjects
- Review recent activity

#### Step 3: Choose a Subject
1. Click on any subject card
2. Review topics covered
3. Check resources and papers available
4. Click "Start Learning" to begin

### 🔍 Search & Filter Guide

#### Basic Search
1. Go to "Search" section
2. Type your query (e.g., "Quantum Mechanics")
3. Results appear instantly

#### Advanced Filtering
- **Type**: Filter by Textbooks, Papers, Guides, Videos
- **Year**: Filter by decade (1980+, 1990+, 2000+, 2010+)
- **Combine**: Use both filters for precision

#### Search Tips
- Use keywords, not full sentences
- Search by topic, author, or discipline
- Filters narrow down results
- Combine multiple filters for precision

### 💾 Data Management

#### Automatic Saving
- All progress saves automatically
- No manual save needed
- Syncs to local browser storage

#### Bookmarking Resources
1. When viewing a resource
2. Click bookmark icon
3. Access later from bookmarks

#### Export Your Data
1. Click profile/settings
2. Select "Export Data"
3. Save JSON file
4. Use for backup or transfer

#### Import Data
1. Click profile/settings
2. Select "Import Data"
3. Choose JSON file
4. All data restores

---

### 🌙 Theme & Preferences

#### Dark Mode
1. Click moon icon (🌙) in navbar
2. Theme switches to dark
3. Preference saves automatically

#### Light Mode
1. Click sun icon (☀️) in navbar
2. Theme switches to light
3. Setting persists across sessions

### ❓ Troubleshooting

#### Issue: Data not saving
**Solution**: Clear browser cache and refresh

#### Issue: Theme not persisting
**Solution**: Enable local storage in browser settings

#### Issue: Slow performance
**Solution**: Clear local storage or use different browser

#### Issue: 3D scene not showing
**Solution**: Update browser or enable WebGL
